Q2What is the bias-variance tradeoff?

Bias is error from wrong assumptions — high bias means the model is too simple (underfitting). Variance is error from sensitivity to the training data — high variance means the model is too complex (overfitting). Reducing one tends to raise the other; the goal is minimising total error, not either term alone.

High BiasHigh Variance
Training errorHighLow
Validation errorHighMuch higher than training
ProblemUnderfittingOverfitting
FixMore complex model, more featuresRegularisation, more data, simpler model

Q3What is overfitting and how do you prevent it?

Overfitting is when a model learns the training data too well — including its noise — and fails to generalise to new data.

Prevention:

  • More data — the single best fix
  • Cross-validation — confirm performance holds on unseen splits
  • Regularisation — L1 (Lasso) and L2 (Ridge) penalise complexity
  • Dropout — randomly drop neurons during training (neural nets)
  • Early stopping — halt once validation loss stops improving
  • Simpler model — fewer parameters, shallower trees
  • Feature selection — remove irrelevant or noisy features

Q5Explain the curse of dimensionality.

As the number of features grows, the volume of the feature space grows exponentially, so:

  • Data becomes sparse — points sit far apart from one another
  • Distance metrics lose meaning — everything drifts toward equidistant
  • Models need exponentially more data to generalise
  • Overfitting risk climbs sharply
Fix: dimensionality reduction (PCA, t-SNE), feature selection, regularisation.

Q6What is cross-validation and why do we use it?

Cross-validation evaluates generalisation by training and testing on different subsets of the data.

K-Fold CV (k=5):
Fold 1: [Test ] [Train] [Train] [Train] [Train]
Fold 2: [Train] [Test ] [Train] [Train] [Train]
Fold 3: [Train] [Train] [Test ] [Train] [Train]
...repeat for all k folds, then average the results
MethodWhen to use
K-Fold (k=5 or 10)Standard default
Stratified K-FoldClass imbalance — preserves class proportions
Time Series SplitTime-ordered data — never leak future into the past
Leave-One-OutVery small datasets

Q9What is the learning rate, and why does it matter?

  • Too high — overshoots the minimum; loss oscillates or diverges
  • Too low — converges painfully slowly, can stall in a local minimum
  • Best practice — start around 1e-3, use a scheduler, or let Adam adapt it automatically

Q15What is data leakage, and why is it dangerous?

Data leakage is information from outside the training set contaminating the model, producing artificially high scores that collapse in production.

Common forms:

  • Scaling the whole dataset before splitting, instead of fitting on train only
  • Including target-correlated features that wouldn't exist at prediction time
  • Using future data to predict past events
  • Filling nulls using statistics computed over the full dataset
Rule: always fit transformers on training data only, then apply to val/test.

Q16What is class imbalance, and how do you handle it?

One class dominates the data — e.g. 99% legitimate transactions, 1% fraud.

  • Resampling — SMOTE (oversample minority), random undersampling
  • Class weights — penalise minority-class errors more heavily
  • Threshold tuning — lower the cutoff (0.5 → 0.3) to catch more positives
  • Better metrics — precision, recall, F1, AUC-ROC instead of accuracy
  • Collect more data for the minority class

Q18What is a confusion matrix?

Predicted: YESPredicted: NO
Actual: YESTP (hit)FN (missed)
Actual: NOFP (false alarm)TN (correct reject)
  • Precision = TP / (TP + FP) — of everything flagged positive, how much was real?
  • Recall = TP / (TP + FN) — of everything actually positive, how much did we catch?
  • F1 = 2 × P × R / (P + R) — harmonic mean, balances both

Q20What is AUC-ROC?

  • ROC curve — plots True Positive Rate vs False Positive Rate across every threshold
  • AUC — one number summarising how well the model discriminates between classes
  • AUC = 0.5 is random guessing, AUC = 1.0 is perfect, 0.85+ is generally strong
Use AUC-ROC when: class imbalance exists and you care about ranking ability, not one fixed threshold.

Know the algorithm, when to use it, how it works, and its failure modes. The “how it works”

answer should take 60 seconds, not 10 minutes.

Q21How does Logistic Regression work?

It models the probability that an input belongs to a class using the sigmoid function:

P(y=1 | X) = 1 / (1 + e^(-z)) where z = wᵀX + b
  • Outputs a probability between 0 and 1
  • Trained by minimising binary cross-entropy (log loss)
  • Decision boundary: predict class 1 if P > 0.5 (tunable)
  • Assumes: a linear relationship between features and log-odds, and features that aren't highly

correlated

Linear RegressionLogistic Regression
OutputContinuous valueProbability (0–1)
ActivationNone (identity)Sigmoid

UseRegressionBinary classification

Q23How does a Decision Tree work?

It splits the data recursively at each node, using the feature and threshold that best separates classes or minimises impurity.

  • Gini impurity — probability of an incorrect classification
  • Entropy / Information Gain — reduction in uncertainty
  • MSE — used for regression trees
Pros / cons: interpretable, no scaling needed, handles mixed types — but overfits easily. Fix with max_depth, min_samples_split, or pruning.

Q24How does Random Forest work, and why is it better than a single tree?

It builds many decision trees on bootstrapped samples, using a random subset of features at each split, then aggregates predictions (majority vote or average).

  • Reduces variance through averaging (bagging)
  • Feature randomness decorrelates trees, making the ensemble more diverse
  • Robust to overfitting and outliers, with built-in feature importance
Key hyperparameters: n_estimators, max_depth, max_features, min_samples_leaf.

Q25How does XGBoost work?

It builds trees sequentially — each new tree corrects the residual errors of all previous trees, using gradient descent in function space.

  • Built-in L1/L2 regularisation
  • Parallel tree construction and native handling of missing values
  • Column subsampling, like Random Forest
Key hyperparameters: n_estimators, learning_rate, max_depth, subsample, colsample_bytree, reg_alpha, reg_lambda.

Q26How does Support Vector Machine (SVM) work?

SVM finds the hyperplane that maximises the margin between classes; the closest points to the boundary are the support vectors.

  • Hard margin — no misclassification allowed (linearly separable data only)
  • Soft margin — allows some misclassification, controlled by C
  • Kernel trick — projects data into higher dimensions to find a linear separator (RBF, polynomial)
Use when: high-dimensional data, text classification, small-to-medium datasets. Avoid for very large datasets or when you need calibrated probabilities.

Q27Explain the K-Nearest Neighbours algorithm.

KNN classifies a new point by finding its K nearest neighbours in the training data and taking the majority class (or average, for regression).

  • No training phase — it's a lazy learner; all computation happens at prediction time
  • Distance metric — Euclidean by default, also Manhattan or cosine
  • Scaling required — unscaled features distort distances
  • Choosing K — small K means high variance, large K means high bias; use cross-validation

Q28What is Naive Bayes, and what makes it “naive”?

A probabilistic classifier built on Bayes' theorem. It's “naive” because it assumes all features are independent given the class — almost never true in practice.

P(Y | X) = P(X | Y) × P(Y) / P(X)
Works well anyway for: text classification, spam filtering, sentiment analysis — because class ranking still holds even when the independence assumption doesn't.

Q29How do you handle multicollinearity?

Multicollinearity is when two or more features are highly correlated, making it hard to isolate each feature's individual effect.

Detection: correlation matrix, Variance Inflation Factor (VIF > 10 is a red flag).

  • Remove one of the correlated features
  • Use PCA to build uncorrelated components
  • Ridge regression (L2) handles collinearity better than plain OLS
  • Tree-based models are largely unaffected by it

Q31What is the precision-recall tradeoff, and how do you tune a threshold?

Lowering the classification threshold (e.g. 0.5 → 0.3) increases recall — you catch more true positives — but reduces precision, since more false positives slip through.

# choose a threshold based on the real cost of each error type

Q33What are the assumptions of Linear Regression?

  • Linearity — relationship between X and y is linear
  • Independence — observations don't influence each other
  • Homoscedasticity — constant variance of residuals
  • Normality of residuals
  • No multicollinearity among features
In practice: tree-based models and neural nets skip these assumptions entirely — one reason they often win on messy real-world data.

Q34What is R², and what are its limitations?

R² measures how much variance in y the model explains, ranging 0–1 (can go negative for a truly bad model).

R² = 1 - SS_residual / SS_total
  • Always increases when you add features — use Adjusted R² instead
  • A high R² doesn't imply a causal relationship
  • Poor indicator of performance on genuinely new data, and sensitive to outliers

Q38What is the difference between hard and soft voting classifiers?

  • Hard voting — takes the majority class label across all models
  • Soft voting — averages predicted probabilities — usually better since it leverages confidence

Q39How do you choose the number of trees in Random Forest?

Use cross-validation — performance typically improves with more trees, then plateaus. 100–500 trees is a common sweet spot. Watch the out-of-bag (OOB) error during training; once it stops decreasing, you have enough trees.

Q40What is early stopping?

A regularisation technique that halts training once validation performance stops improving, avoiding wasted epochs and overfitting.

model = xgb.XGBClassifier(n_estimators=1000)
model.fit(X_train, y_train,
          eval_set=[(X_val, y_val)],
          early_stopping_rounds=50) # stop after 50 rounds with no gain

Q41How does K-Means clustering work?

  • Randomly initialise K cluster centroids
  • Assign each point to its nearest centroid
  • Recompute centroids as the mean of assigned points
  • Repeat until centroids stop moving
Choosing K: elbow method (inertia vs K) or Silhouette score. Limitations: assumes spherical clusters, sensitive to initialisation (use K-Means++), struggles with outliers.

Q42What is the Elbow Method for choosing K?

Plot inertia (sum of squared distances to the nearest centroid) against K. The point where inertia stops dropping sharply — the “elbow” — suggests a good K.

Note: the elbow isn't always obvious — pair it with the Silhouette score.

Q43What is the Silhouette Score?

It measures how well each point fits its own cluster versus neighbouring clusters, ranging from -1 to +1: +1 means well inside its cluster, 0 sits on a boundary, -1 means likely in the wrong cluster.

Q44How does DBSCAN work, and when is it better than K-Means?

DBSCAN groups points that are densely packed — within distance epsilon of at least min_samples neighbours. Points in sparse regions are labelled outliers.

  • Clusters are irregularly shaped
  • You don't know K in advance
  • You need to flag outliers
  • Clusters have different densities (use HDBSCAN for that case)

Q45What is PCA, and how does it work?

PCA finds the directions of maximum variance (principal components) and projects the data onto a lower-dimensional space.

  • Standardise the data
  • Compute the covariance matrix
  • Find eigenvectors (components) and eigenvalues
  • Sort by eigenvalue (explained variance) and project onto the top K
Use for: dimensionality reduction, visualisation, and removing correlated features before linear models.

Q47What is an autoencoder?

A neural network trained to compress data into a smaller representation (encoding) and then reconstruct it (decoding); the bottleneck layer holds the compressed representation.

Uses: dimensionality reduction, anomaly detection (high reconstruction error = anomaly), denoising, generative modelling.

  • Agglomerative (bottom-up) — start with each point as its own cluster, merge closest pairs, build a

  • Divisive (top-down) — start with one cluster, recursively split
Advantage over K-Means: no need to specify K upfront, and the dendrogram shows structure at every level.

Q51What is the difference between hard and soft clustering?

  • Hard clustering — each point belongs to exactly one cluster (K-Means)
  • Soft clustering — each point gets a probability of belonging to each cluster (Gaussian Mixture Models)

Q52What is a Gaussian Mixture Model?

GMM assumes the data comes from a mixture of Gaussian distributions, fitted with the Expectation-Maximisation (EM) algorithm. Each point gets a soft, probabilistic assignment.

Advantage over K-Means: handles elliptical clusters and gives probabilistic assignments.

Q53How does the EM algorithm work?

  • E-step — compute the probability each point belongs to each cluster, given current parameters
  • M-step — update cluster parameters (mean, covariance, weights) to maximise likelihood
  • Repeat until convergence

Q54What is matrix factorisation, and where is it used?

It decomposes a matrix into two lower-rank matrices — the classic application is recommendation systems.

User-Item rating matrix (m×n) ≈ User matrix (m×k) × Item matrix (k×n)
Algorithms: SVD, NMF, ALS — used by Netflix, Spotify, and Amazon for recommendations.

The right metric, chosen for the right reason, is worth more than a fancier model.

Q56When should you use accuracy vs F1 score?

  • Accuracy — fine when classes are balanced and both error types cost the same
  • F1 — needed under class imbalance, or when false positives and false negatives carry different costs
Example: with 99% legitimate transactions and 1% fraud, a model that always predicts “legit” gets 99% accuracy but 0 F1 and catches zero fraud.

Q57What is a learning curve, and how do you read it?

Learning curves plot training and validation error against training set size.

Gap patternDiagnosis
Both errors high and closeUnderfitting — model too simple
Training low, validation high, big gapOverfitting — need more data or regularisation
Both low and closeGood fit
Adding data doesn't helpReached the model's capacity limit

Q58What is RMSE, and when would you use MAE instead?

  • RMSE — penalises large errors heavily; use when big misses are disproportionately bad
  • MAE — treats all errors equally, more robust to outliers
Rule: many outliers in the target → prefer MAE. Large errors especially costly → use RMSE.

Q61What is k-fold cross-validation, and how does it differ from a holdout set?

  • Holdout — split once, evaluate once; results depend heavily on which split you got
  • K-fold — split and evaluate K times, then average; more reliable, and uses all data for both training

and validation

Q62How do you compare two models statistically?

  • Run K-fold CV on both models
  • Compare the mean and standard deviation of the scores
  • Run a paired t-test or Wilcoxon test on the fold-level scores
  • Treat a difference as meaningful only if it exceeds the variation across folds

Q63What is calibration, and why does it matter?

A model is well-calibrated if its predicted probabilities match real-world frequencies — “80% confidence” should turn out correct 80% of the time.

  • Tools: reliability diagram (calibration curve), Brier score
  • Fix: Platt scaling, isotonic regression
Why it matters: if you feed probabilities into pricing or prioritisation decisions, a miscalibrated model quietly produces the wrong expected values.

Q64What is NDCG, and when is it used?

Normalised Discounted Cumulative Gain is a ranking metric that rewards relevant items appearing higher in a list. It's the standard for search engines and recommendation systems.

Q67What is the holdout method, and what are its limitations?

It splits data once into train/test. Limitations: high variance depending on which split you got, and it wastes data since the test set is never used for training. Cross-validation gives a more robust estimate.

Q68What is MAPE, and what are its problems?

Mean Absolute Percentage Error is the mean of |actual − predicted| / |actual|.

  • Undefined when the actual value is 0
  • Asymmetric — punishes under-predictions harder than over-predictions
  • Sensitive to small actuals (an error of 1 on an actual of 2 is a 50% error)
Alternatives: sMAPE, MASE (Mean Absolute Scaled Error).

Q69How do you choose the right evaluation metric for a business problem?

  • Understand the error costs — what's worse, a false positive or false negative? By how much?
  • Understand the output type — probability, rank, or binary label?
  • Understand class balance — balanced → accuracy is fine; imbalanced → F1, AUC
  • Link it to the business KPI — a model that optimises log loss but doesn't move revenue is the wrong

model

🎯 IN THIS SECTION · Q71 – Q82 · 12 QUESTIONS

  • What is target encoding, and what are the risks?

  • …and more

The skill that actually separates good models from bad ones.

Why this section matters: a mediocre model with great features beats a great model with mediocre features. Every single time.

Q71What is feature engineering, and why does it matter?

Feature engineering creates, transforms, or selects input variables to improve model performance — it translates domain knowledge into a representation the model can learn from.

  • Date → day of week, is_weekend, days_since_last_purchase
  • Price → log(price) to reduce skew
  • Lat/Long → distance to the nearest store

Q72How do you handle high-cardinality categorical features?

  • Target encoding — replace the category with the mean target (risk: leakage, use K-fold encoding)
  • Frequency encoding — replace with the category's frequency in training data
  • Embeddings — learn dense representations for neural networks
  • Hashing — map to a fixed-size space, fast but loses interpretability
  • Group rare categories into an “Other” bucket

Q73What is target encoding, and what are the risks?

Target encoding replaces a category with the mean target value for that category.

Risk: leakage — if the mean is computed over rows including the test row, the model effectively sees the target during training.

Fix: K-fold target encoding — compute the encoding using other folds only.

Q74When would you apply a log transformation to a feature?

  • The feature is right-skewed with a long tail of large values
  • The feature has multiplicative relationships (e.g. doubling house size roughly doubles price)
  • The target has high positive skew, or you need to stabilise variance
df['log_revenue'] = np.log1p(df['revenue']) # log1p safely handles 0s

Q75What are interaction features?

New features built by combining two or more existing features, capturing relationships a linear model couldn't see on its own.

df['rooms_per_floor'] = df['rooms'] / df['floors']
df['revenue_per_customer'] = df['revenue'] / df['customer_count']
poly = PolynomialFeatures(degree=2)
X_poly = poly.fit_transform(X) # generates all pairwise products

Q76How do you handle missing values during feature engineering?

First: create a missing indicator — df['age_missing'] = df['age'].isna().astype(int)
  • Numeric — fill with median (robust) or use model-based imputation (KNN Imputer)
  • Categorical — fill with the mode or an “Unknown” category
  • Time series — forward-fill, backward-fill, or interpolate

Never: fill the test set using test-set statistics — always fit on train, transform both.

Q79What is PCA used for in feature engineering specifically?

  • Creating uncorrelated features from correlated ones, before linear models
  • Reducing dimensionality to sidestep the curse of dimensionality
  • Removing noise via low-variance components
  • Visualising high-dimensional data in 2D/3D
Not useful for: tree-based models (which handle correlated features fine), or whenever interpretability is required.

Q80How do you create time-based features from a timestamp?

df['hour'] = df['ts'].dt.hour
df['day_of_week'] = df['ts'].dt.dayofweek # 0=Mon, 6=Sun
df['is_weekend'] = df['day_of_week'].isin([5,6]).astype(int)
df['days_since'] = (df['ts'].max() - df['ts']).dt.days
df['lag_7d'] = df['value'].shift(7) # 7-day lag
df['roll_7d_avg'] = df['value'].rolling(7).mean()

Q81What is oversampling and undersampling?

  • Undersampling — randomly remove majority-class samples; fast but loses data
  • Oversampling — randomly duplicate minority samples; easy but creates exact copies
  • SMOTE — creates synthetic minority samples by interpolating between existing ones; generally better

than random oversampling

from imblearn.over_sampling import SMOTE
X_res, y_res = SMOTE().fit_resample(X_train, y_train)

Q82What is the difference between one-hot encoding and ordinal encoding?

  • One-hot encoding — each category becomes a binary column, no order implied — for nominal

categories

  • Ordinal encoding — categories mapped to integers, order matters — for genuinely ordered categories
Warning: never ordinal-encode a nominal category — it implies a false ordering that misleads linear models.

Q83How does backpropagation work?

Backprop computes the gradient of the loss with respect to every weight using the chain rule, flowing backwards from the output layer to the input layer. Gradient descent then uses those gradients to update the weights.

Forward pass: input → prediction → loss
Backward pass: loss → ∂loss/∂weights (chain rule) → weight update

Q84What is dropout, and how does it prevent overfitting?

During training, a random fraction p of neurons is zeroed out on each forward pass, forcing the network to learn redundant representations — no single neuron can be relied on.

  • At test time all neurons are active, with weights scaled by (1 − p)
  • Typical rates: p = 0.2–0.5
  • Effectively trains an ensemble of exponentially many sub-networks

Q85What are activation functions, and why are they needed?

They introduce non-linearity, without which a deep network would collapse into one linear function.

FunctionFormulaUse
ReLUmax(0, x)Hidden layers (default)
Leaky ReLUmax(0.01x, x)Fixes the dying ReLU problem
Sigmoid1/(1+e^-x)Binary output layer
Softmaxe^x / Σe^xMulti-class output layer
Tanh(e^x - e^-x)/(e^x + e^-x)RNNs, range -1 to 1

Q86What is batch normalisation?

It normalises layer inputs to zero mean and unit variance, then rescales them with learned parameters gamma and beta, applied between layers during training.

Benefits: faster training, higher learning rates tolerated, a mild regularisation effect, and less sensitivity to weight initialisation.

Q87What is a convolutional neural network (CNN), and when do you use it?

CNNs use convolutional layers to detect local patterns — edges, textures, shapes — by sliding a learned filter across the input. Pooling layers downsample, and fully connected layers classify.

Use for: images, video, spatial data — anywhere local patterns matter.

Q88What is an RNN, and what problem does LSTM solve?

  • RNN — processes sequences with a hidden state carried across time steps, but suffers from the

vanishing gradient problem and can't remember long-range dependencies

  • LSTM — adds gates (forget, input, output) to control what information to keep or discard over many

steps, solving that vanishing gradient issue

Q89What is the Transformer architecture?

Transformers process an entire sequence in parallel using self-attention, letting every token attend to every other token.

  • Self-attention — each token computes relevance to every other token
  • Multi-head attention — multiple heads capture different relationships
  • Positional encoding — injects order, since attention alone has none
  • Feed-forward layers — transform each token's representation independently

Q90What is the attention mechanism?

Attention lets the model weight the importance of different parts of the input when producing each output element.

Attention(Q, K, V) = softmax(QKᵀ / √d_k) V
  • Q (Query) — what we're looking for
  • K (Key) — what each token represents
  • V (Value) — what we return for each token

Q91What is transfer learning?

Take a model trained on a large dataset (ImageNet, web text), then fine-tune it on a smaller, task-specific dataset. The pre-trained model already knows general representations; fine-tuning only adapts the later layers.

Why it works: low-level features — edges and textures for images, grammar and semantics for text — are reusable across many tasks.

Q93What are word embeddings, and why are they better than one-hot encoding?

Word embeddings represent words as dense vectors in a continuous space where semantically similar words sit close together.

  • One-hot — 50,000-dimensional, sparse, captures no relationships
  • Word2Vec / GloVe — ~300-dimensional dense vectors; “king − man + woman ≈ queen”
  • Contextual (BERT) — the same word gets a different embedding depending on context

Q94What is the vanishing gradient problem?

In deep networks, gradients shrink exponentially as they propagate backwards through many layers, so early layers receive almost no signal and barely update.

Solutions: ReLU activations, batch normalisation, residual connections (ResNet), LSTM gates, gradient clipping.

Q95What is a GAN?

A Generative Adversarial Network pits two networks against each other:

  • Generator — tries to produce realistic fake data
  • Discriminator — tries to tell real from fake

They compete until the generator's output is indistinguishable from real data — used for image synthesis, data augmentation, and style transfer.

End-to-end thinking — the senior-level differentiator.

This is the senior-level differentiator: anyone can train a model. Very few can design a system that stays reliable, fair, and improving in production.

Q96How would you approach building an ML model from scratch?

  • Understand the business problem — what decision does the model enable, and what's the success

metric?

  • Define the ML task — classification, regression, or ranking?
  • Understand the data — EDA, quality checks, availability at prediction time
  • Establish a baseline — rule-based, heuristic, or simple average
  • Feature engineering — turn domain knowledge into model inputs
  • Model selection and training — start simple, iterate
  • Evaluation — offline metrics tied to the business goal
  • Deploy — API, batch, or embedded
  • Monitor — data drift, model drift, business KPIs

Q97What is model drift, and how do you detect it?

  • Data drift — the distribution of input features changes over time
  • Concept drift — the relationship between features and target changes
  • Label drift — the distribution of the target itself changes
Detection: monitor feature statistics (KS test, PSI), compare prediction distributions, track business KPIs, and set alerts on metric drops.

Q99What is A/B testing in the context of ML?

  • Split users randomly into control (Model A) and treatment (Model B)
  • Run long enough to reach statistical significance
  • Measure the business metric, not just the ML metric
  • Watch for novelty effects, and guard against the multiple-comparisons problem

Q100How do you handle the cold start problem?

  • New user — popularity-based recommendations, onboarding questions, demographic features
  • New item — content-based features, item metadata, editorial curation
  • Hybrid — lean on content signals immediately, blend in collaborative filtering as data builds up

Q102What is MLOps?

The practice of deploying, monitoring, and maintaining ML models in production reliably.

  • Experiment tracking (MLflow, W&B)
  • Model registry — version control for model artifacts
  • CI/CD for ML — automated retrain → test → deploy
  • Monitoring — data drift, performance, latency

Q104What is a feature store, and why is it important?

A centralised system for storing, computing, and serving ML features.

  • Same features used in training and serving — prevents training-serving skew
  • Features computed once and reused across multiple models
  • Supports backfilling historical features
  • Ensures point-in-time correct feature retrieval

Q105How do you detect and mitigate bias in ML models?

Detection: slice performance by demographic group, inspect the confusion matrix per subgroup, run a disparate impact analysis.

  • Pre-processing — balance training data, remove proxy features
  • In-training — fairness constraints, adversarial debiasing
  • Post-processing — equalise odds by adjusting thresholds per group

Q107What is the difference between model accuracy and business 7 impact?

A model with 95% accuracy that doesn't change user behaviour has zero business impact. A model with 80% accuracy that lifts conversion 15% is a genuine success.

  • Define the decision the model actually enables
  • Estimate the impact per unit of decision quality
  • A/B test to confirm actual behaviour change
  • Track the business KPI, not just the ML metric

Q108How do you handle very large datasets that don't fit in memory?

  • Chunked processing — read and process in batches
  • Dask or Spark — distributed computation
  • Feature hashing — map features to fixed-size arrays without materialising every category
  • Sampling — use a representative subset for initial modelling
  • Cloud ML — Vertex AI, SageMaker for managed large-scale training
  • Incremental learning — partial_fit() for online algorithms in sklearn

Q109What is shadow deployment?

The new model runs in parallel with the production model, but its outputs are never shown to users. Real traffic is used to compare predictions silently before committing to the new model — eliminating the risk of exposing users to something untested.

Q110How do you decide when to retrain a model?

  • Scheduled — every N days regardless; simple and predictable
  • Performance-triggered — retrain when a validation metric drops below threshold
  • Drift-triggered — retrain when data drift exceeds a threshold (PSI, KS test)
  • Event-triggered — major business change, new data source, product change
Best practice: automate the trigger, validate before promoting a new model, and always keep a rollback path ready.
